1. Відповідальний за дані

Signal UA — незалежний інформаційний застосунок фізичної особи-розробника, не державний сервіс. Контакт: app.trivoga@gmail.com. Політика описує гілку 1.239 та окремо зазначає сервіси попередніх реалізацій.

2. Дані на пристрої

Локально зберігаються вибрані території, мова, параметри карти, звуку, вібрації, сповіщень, фонового моніторингу, кеш та службові налаштування. Для основних функцій не потрібні акаунт, ім’я, телефон або email. У перевіреному мобільному коді не виявлено рекламного чи аналітичного SDK.

3. Геолокація

За дозволом Android застосунок може отримувати точні або приблизні координати для визначення території та оцінки небезпеки. Координати зіставляються з геоданими на пристрої. Останні відомі координати можуть зберігатися локально й використовуватися фоновим моніторингом. У перевіреному коді не виявлено їх прямого надсилання до API тривог. Запити картографічних плиток можуть розкривати область перегляду, зокрема якщо карта центрована на вашій позиції. Дозвіл можна відкликати в Android, а територію вибрати вручну.

4. Мережеві сервіси

Статуси та історія тривог надходять через API Signal UA на Cloudflare Workers (дані alerts.in.ua). Загрози — через HTTPS та WSS від NEPTUN. Запити можуть містити ідентифікатор вибраної території, IP-адресу, час, заголовки та інші мережеві метадані. Карта звертається до OpenFreeMap та Esri; постачальники бачать запитувані плитки. Старіші реалізації передбачали tryvoha.online, CARTO, unpkg та GitHub Raw — це не перелік активних джерел 1.239. Сайт розміщено на GitHub Pages. Зовнішні сервіси можуть обробляти технічні дані за власними правилами, зокрема за межами України.

5. Дозволи та фонова робота

Інтернет і стан мережі потрібні для оновлень; сповіщення, звук та вібрація — для оповіщень. Фоновий моніторинг і сповіщення ввімкнені за замовчуванням; користувач керує ними. Служба використовує фонову роботу, пробудження пристрою та відновлення після перезавантаження. Виняток з оптимізації батареї надається добровільно. Доступ до геолокації та показ сповіщень залежать від системних дозволів. Вимкнення моніторингу чи дозволів може припинити доставку.

Коли ви пишете на app.trivoga@gmail.com, адреса відправника, лист і вкладення обробляються для відповіді та вирішення звернення. Сторонні сайти і добровільна підтримка через monobank мають власні правила обробки даних. Застосунок не збирає платіжні реквізити у своїй формі.

7. Мета та підстави

Обробка потрібна для надання запитаних функцій, оповіщень, карти, технічної роботи та відповідей на звернення. Залежно від операції застосовується згода, необхідність надання запитаної функції або інша законна підстава. Застосунок не призначений для цілеспрямованого збору персональних даних дітей.

8. Зберігання та видалення

Локальні налаштування і кеш зберігаються до оновлення, очищення або видалення застосунку. Android → Програми → Signal UA → Сховище → Очистити дані. Це скине налаштування; після очищення налаштуйте оповіщення знову. Листування з підтримкою зберігається стільки, скільки обґрунтовано необхідно для вирішення звернення та законних обов’язків. Строки технічних журналів залежать від конфігурації хостингу й постачальників; очищення телефона їх не видаляє. Для запиту щодо даних у розробника пишіть на app.trivoga@gmail.com. Окремого видалення акаунта немає, оскільки застосунок не створює облікових записів.

9. Безпека

Основні мережеві з’єднання використовують HTTPS та WSS. Локальні налаштування зберігаються на пристрої. Абсолютна безпека не гарантується. Не надсилайте паролі, документи або точні координати підтримці без необхідності.
